Built by **Shivaan**. Live at: https://balajibhat.github.io/mystery-mission-hq/

A new secret mission drops every single day. Build it. Crack it. Submit it. Rise to the top.

## How to change your website (2 minutes)

1. Open `index.html` in this repo and click the **pencil icon** (top right) to edit.
2. Make your change.
3. Click **Commit changes** (the green button).
4. Wait 1-2 minutes, then refresh your site (press `Ctrl+Shift+R`). Your change is live on the internet.

Made a mistake? Nothing is ever lost. Every change is saved in the **History**, and any old version can be brought back.

## How to build with AI (the fun way)

1. Open [claude.ai](https://claude.ai) (or whichever AI you use).
2. Paste in the contents of [`CLAUDE.md`](CLAUDE.md) first — that file teaches the AI the rules of YOUR site so it helps properly instead of wrecking things.
3. Then paste in your current `index.html` and say what you want, like:
   - "Add a new mission about designing a video game level"
   - "Make the memory game harder with a 5x5 grid"
   - "Add sound effects when you win"
4. Copy the updated code it gives you back into `index.html` here (pencil icon → select all → paste → commit).
5. Refresh your site. Repeat forever.

**Pro tip:** ask the AI to explain one thing it did each time. That's how you go from using code to writing it.
